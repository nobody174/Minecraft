# Future Features

Features intentionally outside v0.1.0 scope go here. This prevents feature creep.

## v0.2.0 — Expansion (2-3 weeks)

### AI System Expansion
- Advanced goals: Hunt, Explore, Defend, Attack
- Goal priority customization via commands
- Goal interrupt conditions (when to switch goals)
- Emotion system (happy, angry, tired, hungry)

### Commands
- `/buddy follow` — Make buddy follow you
- `/buddy stay` — Make buddy stay in place
- `/buddy list` — List your buddies
- `/buddy name <name>` — Rename buddy
- `/buddy teleport` — Teleport buddy to you

### Customization
- Buddy colors/variants
- Custom names (shown above head)
- Size variants (small, normal, large)
- Personality types (aggressive, friendly, neutral)

### Improvements
- Better multiplayer sync (delta compression)
- Improved animation system
- Status effect visual feedback
- Sound effects

## v0.3.0 — Progression (Future)

### Experience and Leveling
- Buddies gain XP from following player, defeating mobs
- Leveling increases health, damage, speed
- Visual level indicators

### Combat System
- Buddies can attack mobs
- Attack stats: damage, speed, accuracy
- Defense stats: armor, knock-back resistance
- Combat AI (when to attack, retreat, etc.)

### Skills and Training
- Trainable skills (swimming, climbing, flying, etc.)
- Skill books to teach abilities
- Skill cooldowns and limitations

### Social Features
- Multi-buddy parties (work together)
- Breeding mechanics
- Buddy trading
- Leaderboards (most buddies, strongest buddy, etc.)

## v1.0.0 — Polish and Stability

- Community feedback incorporation
- Rare buddy variants (shiny, legendary)
- New biome-specific buddy types
- Config system for server admins
- Performance optimization

## Ideas for Future (Post-1.0.0)

- Buddy dimensions (buddy-only world)
- Buddy crafting (special items only buddies can craft)
- Buddy quests
- Cross-mod integrations
- Buddy skins/cosmetics shop
- PvP arena system

---

**IMPORTANT:** Nothing here goes into v0.1.0. These are for future consideration only.

If a feature seems essential during development, discuss with user before adding to v0.1.0 scope.
