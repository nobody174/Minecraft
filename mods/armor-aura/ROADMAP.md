# ArmorAura Roadmap

## ✅ v1.0.0 (RELEASED)

**Released:** June 21, 2026

### Completed Features
- ✅ 4-ring configurable particle aura system
- ✅ 10+ particle effect types (glow, flame, electric_spark, crit, end_rod, soul, portal, dragon_breath, happy_villager, note)
- ✅ Day/night intensity variation (50% day, 100% night)
- ✅ Full command system with 8 commands
- ✅ JSON-based config file system with hot-reload
- ✅ 3 built-in presets (Minimal, Medium, Maximum)
- ✅ Client-side command registration
- ✅ Real-time config editing (no restart needed)
- ✅ Comprehensive documentation & examples

## 📋 v1.1 (Planned)

### New Features
- **Custom Preset System** — Save and load user-defined presets
- **Keybind Shortcuts** — Quick preset switching without commands
- **Color Customization** — RGB control for aura tinting
- **Ring-Specific Effects** — Different particle types per ring
- **Performance Profiles** — Auto-adjust based on detected FPS

### Improvements
- Better in-game config editor (interactive menu)
- Preset sharing via configuration files
- Extended particle type library

## 🎯 v1.2+ (Long-Term Ideas)

### Server Integration
- Multi-player aura syncing (show other players' auras)
- Server-side aura persistence
- Permission-based customization limits

### Sound System
- Ambient aura sounds with configurable volume/pitch
- Different sounds per effect type
- Day/night sound variation

### Advanced Features
- Custom armor enchantment integration
- Multiple aura types (spiral, pulse, static wave)
- Animated gradients and transitions
- Performance optimizations for low-end hardware

### Content Expansion
- Mod compatibility (e.g., Apotheosis enchantments)
- Armor material-specific effects
- Creative mode enhancements
