# Changelog

All notable changes to Buddy Beast are documented here.

## [0.1.0] - In Development

### Added
- Initial project setup and structure
- Basic entity registration
- Goal-based AI framework
- Taming mechanic
- Data persistence system
- Network synchronization foundation
- Custom entity rendering

### Planned
- Complete entity model and texture
- Full AI goal implementation
- Multiplayer testing
- Performance optimization
- Bug fixes and stability improvements

## Versioning

Versions follow Semantic Versioning:
- **Patch (x.x.Z)** — Bug fixes, stability improvements
- **Minor (x.Y.0)** — New features, system expansions
- **Major (X.0.0)** — Large system overhauls, breaking changes
